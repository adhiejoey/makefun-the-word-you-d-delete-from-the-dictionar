This entry erases **forever** from the dictionary — forever. The deletion
defeats itself the moment it happens: without the word, nothing can ever be
gone forever again, not even the deletion, so the dictionary is stuck keeping
everything it was trying to throw away, for a length of time it can no longer
name.

## How it works

`main.ts` writes the single word `forever` to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), with no trailing newline and nothing else
attached.
